Python Practice Tasks 🐍

A collection of 10 Python tasks designed to refresh and improve my Python programming skills. The tasks gradually increase in difficulty and cover different areas of Python, from basic syntax and control flow to OOP and file handling.

Tasks
Calculator — A simple calculator that performs basic mathematical operations and handles division by zero.
Guess the Number — A game where the computer generates a random number and the player tries to guess it.
String Analyzer — Analyzes user input by counting characters, words, vowels, and finding the longest word.
Shopping List — A console-based shopping list with options to add, remove, view, and clear items.
Phone Book — A simple contact manager using dictionaries, allowing users to add, find, delete, and display contacts.
Grade Statistics — Processes a list of grades and calculates the average, minimum, maximum, and other statistics.
Bank Account — An introduction to Object-Oriented Programming with a BankAccount class for managing deposits, withdrawals, and balance.
Notes App — A simple text-based notes application that stores and loads notes using a .txt file.
Password Manager — A basic account and password manager with file storage and a random password generator.
Text RPG Game — A small console RPG combining classes, functions, lists, dictionaries, random numbers, file handling, JSON, and basic game mechanics.
Goal

The main goal of this project is to practice Python through small practical projects and gradually rebuild my programming skills. Each task focuses on different Python concepts while keeping the projects simple enough to understand and expand.
